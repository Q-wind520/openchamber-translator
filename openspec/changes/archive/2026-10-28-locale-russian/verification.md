# Проверка реализации locale-russian

Дата: 2026-10-28. Состояние: **19/19 задач выполнены**. Пункт 5.2 проверен в настоящем хосте; обработка NO_MODEL проверена ручным тестовым ответом по решению пользователя. Коммиты реализации и архивирование не выполнялись.

Команды сборки и HTTP-сервера для браузерных фикстур приведены в README обоих языков. Chromium-совместимый браузер уже установлен: `/opt/google/chrome/chrome`, Google Chrome 156.0.8078.47. ## Поведенческие свидетельства

- До изменений UI первый сценарий и затем все 8 сценариев давали FAIL `Missing #ui-language`. После реализации все проходят.
- Тесты предпочтений до реализации падали из-за отсутствующего `uiLanguage`; тесты локализации не могли импортировать ещё не созданный модуль. Проверены старые данные, ручные значения, `auto`, отсутствие записи при чтении и fallback при ошибке storage.
- Startup-фикстура с исходной `src/main.ts` из `HEAD` во временной сборке даёт 4 FAIL: китайский тайм-аут, ошибка монтирования не на сохранённом языке, игнорирование позднего ready и старый контекст после отложенного storage. С текущей реализацией — 4 PASS. Исходник в рабочем дереве для этого не откатывался.
- Найден и исправлен дополнительный случай: ошибка провайдера без диагностического сообщения добавляла китайский fallback. Новый тест с `throw null` сначала падал; теперь UI использует локализованное общее сообщение без придуманной диагностики.
- Браузерные assertions проверяют идентичность textarea и узлов результата, содержимое, выделение, режим и свёрнутость, реально ненулевую прокрутку оригинала/результата/карточки, отсутствие дополнительных generate при смене UI, состояние активного запроса и отмены, отложенное чтение clipboard, таймер копирования, ошибки/лимиты, сохранение и восстановление выбора.
- Известные причины ошибок, включая `incomplete-result`, имеют отдельные проверенные сообщения на трёх языках. Защитная ветка неполного результата после успешной проверки всех batches не воспроизводится через штатный провайдер; искусственный тест, обходящий валидацию ради покрытия этой ветки, не добавлялся. Алгоритм планирования и промпт не менялись.
- Отдельно через нативный `Input.dispatchKeyEvent` проверен `ArrowUp` на селекторе: `ru → en`, изменение `html.lang` и сохранение оригинала.

## Проверка установленного расширения в настоящем хосте: 5.2

- Адрес: `http://127.0.0.1:5096/`; установленная версия OpenChamber CLI — **2.5.2**. В конфигурации расширений подтверждён путь `/home/dev/apps/openchamber-translator`, в интерфейсе открыта именно панель Translator. Все действия выполнены через MCP `browsermcp`.
- Ручные языки: проверены подписи English, 简体中文 и Русский. Режим `auto` переключил интерфейс на английский язык хоста; ручной русский выбор восстановлен.
- Настоящий запрос Small Model перевёл безопасный тестовый текст `Hello, world.` в `こんにちは、世界。` при целевом языке `ja`. После смены языка интерфейса сохранились оригинал, полученный результат и целевой язык `ja`. Проверено также сохранение свёрнутости при переключении на английский и сохранность результата после разворачивания.
- После закрытия/открытия панели и полной перезагрузки страницы сохранён ручной выбор `ru`; оригинал после полной перезагрузки пуст, как и предусмотрено отсутствием его постоянного сохранения.
- Снимки только установленной панели, без основного чата и экрана входа: `node_modules/.cache/locale-russian-host/host-ru-320.jpg` и `host-en-360.jpg`. Фактическая ширина iframe подтверждена как 320 и 360 CSS-пикселей; основные подписи, действия и результат не обрезаны. Эти временные файлы игнорируются Git.
- Пользователь разрешил временно убрать выбранную Small Model. После выбора `Not selected` настоящий хост всё равно успешно перевёл текст, то есть использовал автоматический fallback. Исходная **GPT-6 Luna восстановлена**; провайдеры не изменялись. Исходные предпочтения расширения восстановлены: русский интерфейс, целевой язык `en`, автоперевод выделения выключен, оригинал и тестовый результат очищены. Временное ограничение ширины iframe снято.
- Автоматическая подмена ответа `NO_MODEL` не выполнялась: пользователь попросил инструкции и самостоятельно подал одноразовый тестовый ответ через Console для установленной панели. Затем через `question` подтвердил «Русская инструкция Small Model».
- Независимо от подтверждения пользователя через `browsermcp` прочитано фактическое сообщение панели: «Small Model не настроена. Выберите модель в Настройки → Сессии → Small Model и повторите попытку.» Подтверждена кнопка «Повторить»; снимок только панели сохранён как `node_modules/.cache/locale-russian-host/host-no-model-ru.jpg`.
- Граница свидетельства: обработка NO_MODEL внутри настоящего iframe проверена, но отсутствие всех реально доступных моделей на сервере не создавалось. Отсутствие назначенной Small Model на этом хосте само по себе не доказывает получение NO_MODEL. Провайдеры не отключались, глобальная модель восстановлена; последующий ручной выбор целевого языка пользователем не перезаписывался.

## Повторная верификация по артефактам

Навык `openspec-verify-change` недоступен в текущем runtime; вызов `skill` вернул ошибку загрузки, соответствующий локальный SKILL.md не найден. Проверка выполнена напрямую, без утверждения об успешной загрузке навыка. Пользователь явно принял прямую проверку через `question`.

| Требование спецификации | Реализация и свидетельства |
| --- | --- |
| Interface language selection | Селектор в `src/panel/template.ts`, ручной приоритет в `i18n.ts`; unit/browser-проверки и ранее проведённый тест установленной панели |
| Automatic locale resolution | `resolveUiLocale`, таблица локалей в `test/i18n.test.ts`, обновление ready в `main.ts` и startup-фикстуре |
| Preference persistence and compatibility | `preferences-v2`, нормализация `auto`, сохранение очередью; тесты старых настроек/ошибок storage и ранее проверенная перезагрузка настоящего хоста |
| Immediate non-destructive switching | `applyLocale` обновляет подписи без построения абзацев; браузерные assertions состояния, выделения, прокрутки и отсутствия лишних запросов |
| Translation target independence | Отдельное поле `uiLanguage`, существующее определение целевых языков не изменено; тест `ja` и настоящий японский результат в установленной панели |
| Complete panel localization | Три полных словаря и привязки атрибутов; `html.lang`, числовые формы, прежние снимки 320/360 px и проверки доступных подписей |
| Localized error presentation | Типизированные причины и параметры, `textContent` для диагностики; unit/browser-проверки и ручной NO_MODEL с последующим чтением через MCP |
| Startup and host-owned message boundary | Английский HTML/тайм-аут, однократная загрузка предпочтений, последний ready, перевод будущих toast; код и четыре ранее выполненных startup-сценария |

Свежие результаты текущего прогона:
- `npm run typecheck`, `npm test` — exit 0; 48 тестов в 4 файлах.
- `openspec validate locale-russian --strict`, `git diff --check` — exit 0; OpenSpec сообщает 19/19 завершённых задач и `all_done`.
- Сборка esbuild с `write: false` побайтово совпала с `panel/main.js`; установленный бандл не перезаписывался. `package.json`/lockfile и определения целевых языков не изменены.
- Независимый Code Reviewer повторно сопоставил рабочее дерево с proposal/spec/design/tasks: подтверждённых существенных дефектов не найдено.
- Браузерные фикстуры пересобраны во временный каталог, но повторный браузерный прогон **не выполнялся по явному выбору пользователя**. Браузерные и хостовые результаты выше относятся к уже проведённым проверкам, не к новому запуску.

Неблокирующие пробелы покрытия: нет отдельных browser-сценариев отложенного успешного/ошибочного завершения `writeClipboard` после смены языка, а также успешного завершения многочастного полного перевода после смены языка с сохранением ненулевой полосы прогресса. Обработчики используют текущую локаль, а обновление подписей не меняет сохранённые данные прогресса, но это чтение кода не заменяет отсутствующие отдельные сценарии. Эти пути не объявляются заново проверенными; подтверждённой ошибки реализации не обнаружено.
