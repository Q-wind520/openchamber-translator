# OpenChamber Translator

Расширение для боковой панели OpenChamber, предназначенное прежде всего для **перевода текста целиком**. Также поддерживает **автоматический перевод выделенного текста** прямо в поле с оригиналом.

- Переводит длинные тексты по абзацам и позволяет переключаться между режимами «Оригинал и перевод / Перевод / Оригинал».
- Ограничивает высоту карточки с переводом и позволяет прокручивать её содержимое, а также сворачивать и разворачивать карточку одним нажатием, чтобы длинный текст не занимал всю боковую панель.
- Автоматически переводит текст, выделенный в оригинале, и показывает результат в отдельной карточке — нажимать кнопку перевода не требуется.
- Использует уже настроенную в OpenChamber **Small Model**, поэтому отдельно указывать API-ключ в расширении не нужно.
- Если DeepSeek уже настроен в OpenCode, достаточно выбрать его в качестве Small Model.
- Показывает прогресс перевода, позволяет отменить процесс и скопировать результат одним нажатием.
- Автоматически подстраивается под светлую или тёмную тему и шрифты OpenChamber.

## Системные требования

- OpenChamber `>= 2.5.1` (веб-версия или настольное приложение).
- Node.js `>= 22.12` (требуется только для сборки).

## Сборка и установка

```bash
npm install
npm run check
```

Результат сборки — файл `panel/main.js`. OpenChamber не компилирует исходный код расширений, поэтому перед установкой расширение необходимо собрать.

В OpenChamber:

1. Откройте **Настройки → Расширения**.
2. В поле «Папка, ZIP или URL» укажите абсолютный путь к текущему репозиторию, например:
   `/path/to/openchamber-translation`
3. Нажмите кнопку добавления и предоставьте разрешение «Использовать вашу Small Model».
4. Нажмите значок «Translator» на правой боковой панели, чтобы открыть расширение.

Во время разработки можно устанавливать расширение непосредственно из папки: после изменения файлов в `src/` запустите `npm run dev` (или `npm run build`), затем перезагрузите панель.

## Использование DeepSeek / переключение модели

Расширение не хранит отдельный API-ключ модели и не отправляет запросы напрямую в DeepSeek. Вместо этого оно использует настроенную Small Model через метод `host.generate` из OpenChamber SDK:

1. Убедитесь, что DeepSeek настроен в списке провайдеров OpenCode / OpenChamber.
2. Откройте **Настройки → Сессии → Small Model**.
3. Выберите модель DeepSeek, например `deepseek/deepseek-flash`.
4. Вернитесь в панель «Translator» и приступайте к переводу.

> API расширений OpenChamber предоставляет только возможность генерации через Small Model. Расширение не может самостоятельно выбирать конкретного провайдера или модель либо получать сведения о них. Поэтому фактически используемая модель определяется настройкой Small Model.
>
> Если текущая Small Model недоступна, на панели появится сообщение об отсутствии доступной модели. Измените настройки и повторите попытку.

## Способы перевода

### Перевод текста целиком

1. Вставьте статью или Markdown в поле ввода либо нажмите кнопку «Буфер обмена», чтобы вставить содержимое буфера.
2. Выберите целевой язык и нажмите «Перевести всё» или сочетание клавиш `Ctrl/Cmd + Enter`.
3. Во время перевода можно отслеживать количество обработанных абзацев и отменить процесс.
4. Доступны три режима отображения результата:
   - **Оригинал и перевод**: оригинал и перевод отображаются рядом для каждого абзаца;
   - **Перевод**: отображается только перевод;
   - **Оригинал**: отображается только исходный текст.
5. По умолчанию максимальная высота области перевода составляет около 52% высоты окна (но не более 520 px). Если текст не помещается, его можно прокручивать внутри карточки. Кнопка сворачивания на панели инструментов позволяет свернуть перевод до одной строки.
6. Кнопка копирования в правом верхнем углу копирует только перевод.

За один запуск можно перевести не более 50 000 символов. Длинный текст разбивается на абзацы по пустым строкам, а слишком длинные абзацы дополнительно разделяются по границам предложений. Каждый фрагмент отправляется модели отдельно, поэтому перевод длинного текста требует большего количества обращений к модели.

### Автоматический перевод выделенного текста

1. Переключатель «Автоперевод выделенного» в верхней части редактора включён по умолчанию. Если его выключить, выделенный текст не будет переводиться автоматически.
2. Выделите текст мышью или клавиатурой в поле «Оригинал». Примерно через 450 мс перевод запустится автоматически, без нажатия кнопки.
3. Результат появится в карточке «Перевод выделенного» под исходным текстом. Его можно скопировать, закрыть или повторить попытку в случае ошибки.
4. При последовательном изменении выделения запросы выполняются строго по очереди, при этом учитывается только последнее выделение. Результаты предыдущих запросов, которые ещё выполняются, отбрасываются.
5. За один раз можно перевести не более 2 000 выделенных символов. Это предотвращает лишние обращения к модели при случайном выделении большого текста. Для более длинного содержимого используйте перевод текста целиком.

Автоматический перевод выделенного текста работает только в поле исходного текста внутри панели расширения. Он не считывает выделения на других страницах OpenChamber или браузера.

## Разрешения и конфиденциальность

Расширение запрашивает только одну возможность:

```json
"capabilities": ["model"]
```

- Не обращается к сети напрямую, не запускает локальные службы и не читает файлы проекта.
- Не запрашивает интеграции со сторонними сервисами перевода и не требует отдельной настройки API-ключа.
- Исходный текст передаётся через Small Model OpenChamber провайдеру модели, настроенному в OpenCode. При этом расходуется квота соответствующей модели.
- Исходный текст, перевод и настройки не записываются в сессии OpenChamber. Постоянно сохраняются только целевой язык, режим отображения и состояние переключателя автоматического перевода выделенного текста.
- При копировании больших результатов действует ограничение буфера обмена OpenChamber в 32 000 символов. Если результат больше, копируйте его по частям.

## Разработка

```bash
npm run dev        # esbuild в режиме отслеживания изменений -> panel/main.js
npm run typecheck  # tsc --noEmit
npm test           # модульные тесты Vitest
npm run check      # проверка типов + тесты + production-сборка
```

Структура каталогов:

```text
src/
  main.ts                     Инициализация хоста OpenChamber и интеграция с темой
  panel/
    app.ts                    Перевод текста целиком, перевод выделенного текста и взаимодействие с карточками
    preferences.ts            Сохранение целевого языка и режима отображения
    template.ts               Статическая структура панели
  translation/
    plan.ts                   Разбиение на абзацы и длинные предложения, пакетная обработка, прогресс и отмена
    errors.ts                 Типы ошибок
    languages.ts              Целевые языки
    providers/
      opencode.ts             Вызов перевода через host.generate
panel/
  index.html                  Точка входа расширения
  style.css                   Стили панели (используют переменные темы хоста)
  main.js                     Результат сборки
icon.svg                      Значок боковой панели
build.mjs                     Скрипт сборки (IIFE)
```

## Ограничения

- Поскольку используется Small Model, скорость и качество перевода зависят от модели, настроенной в OpenChamber.
- Максимальный размер одного фрагмента в запросе к модели — 2 000 символов, а одного текста для полного перевода — 50 000 символов.
- Отмена останавливает отправку последующих фрагментов, однако уже запущенный запрос к модели может завершиться.
- Перевод скриншотов и внедрение в DOM целой страницы не поддерживаются. Перевод выделенного текста работает только в поле оригинала внутри панели: песочница OpenChamber не позволяет расширениям читать выделенный текст с внешних страниц.
- Когда выделение перестаёт изменяться, автоматический перевод отправляет запрос к модели и расходует квоту Small Model. Если функция не нужна, можно закрыть карточку перевода выделенного текста, чтобы сократить количество случайных обращений.
